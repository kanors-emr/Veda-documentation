# Fill colors

## What it is for

The **Fill colors** group on the **VEDA** ribbon is a key for the shading **Add Tag** and **Evaluate Row** put on a tag data row. It sits after **Session**. The swatches do not run a command.

| Swatch | Cell |
|--------|------|
| **Required** (light red) | An empty required dimension cell (process, commodity, and similar) |
| **Value** (light gray) | An empty value cell: the `value` column, or an expanded region, year, or timeslice header |

## How to use

1. Insert or open a tag table ([Add Tag](add-tag.md)).
2. Pick an attribute in the pane, or type a known attribute into an empty attribute cell ([Evaluate Row](evaluate-row.md)).
3. On that data row, read the shading against the ribbon key. A light red cell still needs a required dimension. A light gray cell still needs a value.

The key is only on the ribbon. It is not on the cell right-click menu.
