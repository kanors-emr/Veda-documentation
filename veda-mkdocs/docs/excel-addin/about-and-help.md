# About and help

## What it is for

**About** identifies the add-in provider and reminds you that **VEDA 2.0** must be running with the model you use. Short topic help dialogs explain Add Tag and Cell Info without leaving Excel.

## How to use

1. On the **VEDA** ribbon or right-click **VEDA** menu, choose **About**.
2. On the Cell(s) Info window, use **About** for Cell Info–specific help.
3. In Add Tag flows, use **About Add Tag** (where shown) for tag-related help.

## Requirements (same for all help topics)

- VEDA 2.0 is running on this machine.
- The model linked to your workbook folder is imported ([How models are linked](how-models-are-linked.md)).
- For data features, connection and workbook rules still apply ([How we connect](how-we-connect.md), [Workbook recognition](workbook-recognition.md)).
